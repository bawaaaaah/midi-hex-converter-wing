Mappage MIDI Behringer Wing (Port Control / Port 4)

Activez la réception dans SETUP → REMOTE. Les valeurs CC vont de 0 à 127.

Faders (CH1) • Mute (CH2) • Pan (CH3)

CCCible
12–31Channel 1 à 20
44–63Channel 21 à 40
70–77Aux 1 à 8
78–93Bus 1 à 16
94 / 95Main 1 / Main 2
102 / 103Main 3 / Main 4
104–111Matrix 1 à 8

Exemple : Fader Channel 1 → CH1 CC12 | Mute Channel 1 → CH2 CC12 | Pan Channel 1 → CH3 CC12

DCA Faders (CH4) • DCA Mute & Mute Groups (CH5)

CCCible
12–27DCA 1 à 16 (Fader sur CH4 / Mute sur CH5)
28–31Mute Group 1 à 4 (CH5)
44–47Mute Group 5 à 8 (CH5)

Custom Controls (CH6) — RX uniquement

TypePlageCible
CC Rotaries12–15 … 90–93Layer 1 à 16 (4 rotaries par layer)
Note ButtonsNote 0–7 … 120–127Layer 1 à 16 (8 boutons par layer)

Layer 1 rotaries = CC12-15 | Layer 1 buttons = Note 0-7 (upper + lower row)

Show / Scene Control (le plus utile pour les scènes)

CanalMessageAction
CH7Program Change 0–127Charge la scène n°1 à 128 (index dans le Show)
CH8Program Change 0–127Charge la scène avec le Tag #1 à #128
CH9PC 1Scene GO
CH9PC 2Scene PREV
CH9PC 3Scene NEXT
CH9PC 4GO + PREV
CH9PC 5GO + NEXT

• Pour utiliser les Tags : dans LIBRARY → SHOW → sélectionner la scène → Edit Tag → #1, #2…
• Le Show doit être ouvert pour que ces commandes fonctionnent.
• Exemple Tag #1 → C8 00 (Program Change 0 sur canal 8)
