Paramètres FX (CH9–16)

FX1–8 (FX1→CH9 … FX8→CH16) : CC12=Insert ON/OFF • CC13=Mix • CC14=Modèle • CC15-31=Param 1-17 • CC44-58=Param 18-32
FX9–16 (FX9→CH9 … FX16→CH16, mêmes canaux que FX1-8) : CC70=Insert ON/OFF • CC71=Mix • CC72=Modèle • CC73-95=Param 1-23 • CC102-111=Param 24-33

Modèles disponibles — Effets standards (fx/N/mdl)

Règle le slot FX ci-dessus puis clique sur un paramètre pour générer directement son CC/hex dans le Convertisseur (le n° de modèle exact envoyé par CC14/CC72 n'est en revanche pas documenté publiquement — passe par OSC /fx/N/mdl pour forcer un modèle précisément).
